#docker

Libera espacio de disco en Linux Mint

Comandos para localizar qué ocupa espacio y recuperar espacio de disco en Linux Mint y Ubuntu.

Antes de empezar:

  • Ejecuta primero los diagnósticos.
  • Las limpiezas pueden eliminar archivos o recursos que aún necesitas.
  • Lee cada advertencia antes del comando.

1. Comprueba el espacio disponible

df -h /

Filesystem      Size  Used Avail Use% Mounted on
/dev/nvme0n1p2  220G  185G   24G  89% /

2. Encuentra los directorios más grandes

Analiza el sistema de archivos raíz sin atravesar otros sistemas montados.

sudo du -xhd1 / 2>/dev/null | sort -hr | head -10

185G    /
92G     /home
48G     /var
19G     /usr
8.2G    /opt

Profundiza donde encuentres mayor consumo:

sudo du -xhd1 /var 2>/dev/null | sort -hr | head -10

3. Limpiar la caché de APT

Comprueba cuánto ocupan los paquetes descargados:

sudo du -sh /var/cache/apt/archives

El siguiente comando borrará los paquetes .deb almacenados en caché, no las aplicaciones instaladas. Una reinstalación podría requerir descargarlos nuevamente.

sudo apt clean

4. Eliminar dependencias APT sin utilizar

Primero simula la operación para revisar qué paquetes se eliminarían:

sudo apt -s autoremove --purge

El siguiente comando desinstala paquetes marcados como innecesarios. Comprueba la lista, especialmente si utilizas herramientas de desarrollo o paquetes instalados manualmente.

sudo apt autoremove --purge

5. Reducir registros de systemd

Consulta el espacio utilizado:

journalctl --disk-usage

Archived and active journals take up 1.5G in the file system.

El siguiente comando elimina registros archivados anteriores a siete días, podrías necesitarlos para diagnosticar incidentes. No elimina los registros activos.

sudo journalctl --vacuum-time=7d

6. Limpiar miniaturas

du -sh ~/.cache/thumbnails 2>/dev/null

El siguiente comando eliminará solo las miniaturas en caché, no las fotografías originales. El explorador las regenerará cuando sea necesario.

find ~/.cache/thumbnails -mindepth 1 -maxdepth 1 -exec rm -rf -- {} +

7. Vaciar la papelera

Revisa los archivos antes de eliminarlos:

gio trash --list

El siguiente comando vacía la papelera del usuario. Los archivos ya no podrán restaurarse desde ella. Comprueba la lista anterior.

gio trash --empty

8. Revisar cachés de aplicaciones

du -h --max-depth=1 ~/.cache 2>/dev/null | sort -hr | head -10

Caché de pip

python3 -m pip cache info

El siguiente comando elimina las descargas almacenadas por pip, no desinstala los paquetes ya instalados.

python3 -m pip cache purge

Caché de npm

npm cache ls | head -20

Este comando limpia la caché de npm, pero las instalaciones posteriores podrían descargar paquetes otra vez.

npm cache clean --force

No borres todo ~/.cache indiscriminadamente, algunas aplicaciones guardan allí datos útiles.

9. Eliminar componentes Flatpak sin uso

flatpak list --runtime

El siguiente comando elimina runtimes y extensiones que Flatpak considera sin uso. Revisa la lista que muestra antes de confirmar.

flatpak uninstall --unused

10. Revisar y limpiar Docker

Consulta cuánto ocupan imágenes, contenedores, volúmenes y caché:

docker system df -v

Revisa los contenedores, incluidos los detenidos:

docker ps -a

Limpia la caché de compilación

Advertencia: elimina caché de compilación no utilizada; los próximos docker build podrían tardar más. No elimina volúmenes de datos.

docker builder prune

Limpiar recursos Docker no utilizados

Peligro: docker system prune elimina todos los contenedores detenidos, redes sin uso, imágenes colgantes y caché de compilación. Un contenedor detenido puede contener datos importantes en su capa de escritura. Verifica docker ps -a y respalda lo necesario antes de confirmar. El comando sin --volumes no elimina los volúmenes.

docker system prune

Peligro: no ejecutes docker volume prune ni docker system prune --volumes sin revisar los volúmenes. Podrían contener bases de datos de PostgreSQL, MariaDB, Redis u otros servicios.

11. Buscar archivos grandes en el directorio personal

Muestra los 20 archivos de más de 500 MiB, ordenados por tamaño:

find "$HOME" -type f -size +500M -printf '%s %p\n' 2>/dev/null | sort -nr | head -20 | numfmt --field=1 --to=iec

8.2G /home/user/Downloads/backup.sql
3.5G /home/user/Videos/video.mp4
1.8G /home/user/Downloads/imagen.iso

12. Verificar el espacio recuperado

df -h /

Filesystem      Size  Used Avail Use% Mounted on
/dev/nvme0n1p2  220G  169G   40G  81% /
